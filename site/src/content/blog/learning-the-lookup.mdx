export const B = full.by_bucket;
export const ci = (x) => `${x.ci95[0] >= 0 ? '+' : '−'}${Math.abs(x.ci95[0]).toFixed(2)} to +${x.ci95[1].toFixed(2)}`;
export const n = (x) => x.positions.toLocaleString('en-US');
export const bands = [b7, b11, b15, b19, b23].map((b) => b.personal);
export const pooled = (get) => {
  const rows = bands.map(get);
  const pos = rows.reduce((s, r) => s + r.positions, 0);
  return rows.reduce((s, r) => s + r.positions * r.gain_pts, 0) / pos;
};
export const ply = (k) => { const v = pooled((b) => b.by_ply[k]); return Math.abs(v) < 0.005 ? 0 : v; };

The last post ended with a plan: our first retrieval try found the positions in a player's earlier games that look
most like the one on the board, and let those vote. It had no training, and it only worked when a near-copy existed.
The next step was to learn the lookup.

We did. On all 884,049 positions of the standard test set, the learned lookup's top choice matches the move the
player made **57.44%** of the time. Maia-3 alone gets 57.08%. The gain is **+0.36 points** (95% interval
{ci(full.lookup_vs_maia)}).

One note on what this number is. The test set was built to score models that see only the board. We also give the
model up to 40 of the player's earlier games, so this is a different setting, "the Allie test with prior player
history", and not an entry on the usual leaderboard.

## What the lookup does

For each position, it looks through the player's 40 most recent earlier games, as Maia-3 sees them. A small learned
head decides how similar each stored position is and how much to trust the match. The stored positions then vote
with the move the player made there, and that vote nudges Maia-3's probabilities.

The head was trained on 2026 games from 2,000 players per rating band. Nothing was tuned on the test set. Maia-3
stays frozen.

All five bands clear zero. That includes 2000 and up, where the Doppel's player description adds nothing at all
(+0.00). The two run in opposite directions. The player description helps most for weaker players
(+0.26 points at 1000–1400) and fades as ratings rise. The lookup grows with rating up to 2000, because stronger
players repeat their own lines more.

## Whose games matter

Is the lookup just a good way to use more chess data? To check, we gave each player a store of 40 games from a
different, randomly chosen player.

wrong person's habits cost accuracy. The gain is personal.

Almost all of it is in the opening. In plies 10 to 19 the lookup gains 1.5 points, and nearly 90% of the total
gain comes from there. After ply 30 it adds nothing.

But it is not just exact repeats. Exact repeats of an earlier position are only 12,029 of the 884,049 positions.
They gain 6.5 points each, which is about a quarter of the total. The rest comes from positions that are close to
something the player has seen but not identical:

The untrained version from the last post gained nothing in the 0.8–0.9 range. The learned one gains 1.2 points
there, and that range holds 36,532 positions.

## Does it predict blunders?

A coaching tool cares less about routine moves than about mistakes. So we checked the positions where the player
actually blundered (lost at least 0.2 of a game's expected score, by Stockfish). How often is the model's top move
that exact blunder?

Maia-3 already predicts the exact blunder about 22% of the time, in every band we checked. In the 1400–1600 band the
learned lookup adds {L['blunder (>=0.2)'].top1_diff_pts.toFixed(2)} points on blunders
({L['blunder (>=0.2)'].n.toLocaleString('en-US')} positions; interval +{L['blunder (>=0.2)'].top1_diff_ci_pts[0].toFixed(2)}
to +{L['blunder (>=0.2)'].top1_diff_ci_pts[1].toFixed(2)}), against {L['good (<0.05)'].top1_diff_pts.toFixed(2)} on good
moves. Part of what it learns is a player's own repeated errors. The interval is wide: 5,143 blunders is not
many.

## How big is that?

Still small: 36 more correct moves per 10,000. But it is about a third of the spread between the best published
models on this test, it comes from the player alone, and it beats the last post's best combination, the Doppel plus the exact-repeat lookup
(57.39% on the whole test set), with no player description at all.

Two caveats:

1. **It lives in the opening.** In the middlegame and endgame it adds nothing. Recognising a player's style in a
   new position is still open.
2. **We have not combined it with the player description yet.** The two help different players, so they may add up.
   That is the next experiment.
